# 📩 Contact Form with Validation

## Description

A simple contact form built using HTML, CSS, and JavaScript with client-side validation.

## Features

- Name, Email, Message validation

- Email validation using regex

- Error messages for invalid inputs

- Success message on valid submission

- Attractive animated UI

## Technologies Used

- HTML

- CSS

- JavaScript

## How to Run

Open `index.html` in any browser.

## Output

User-friendly contact form with real-time validation.# contact_form
